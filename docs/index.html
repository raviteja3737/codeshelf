codeshelf

A tiny terminal app to find a saved snippet by its title and copy it, without opening any file.

How it works

Type codes and press Enter. You get a list of snippet titles.

  • ↑ ↓ move through the list; typing letters filters it
  • Enter shows the full snippet (scroll with the arrows, Esc goes back)
  • Space copies the snippet to your clipboard
  • Esc quits

Install on Windows (cmd)

One line. It downloads a single ~2 MB file into a folder that is already on your PATH, then starts the app. Nothing else needs to be installed.

curl -sL raviteja3737.github.io/codeshelf/c|cmd&codes

After that, just type codes. Run the same line again to update.

Mac and Linux

Builds for macOS (Intel and Apple Silicon) and Linux (amd64, arm64) are on the releases page. Linux copying needs xclip or wl-clipboard.

Why it exists

I keep a set of commands and code snippets that I reuse across many machines. Opening files to find them is slow, so codeshelf is a single static binary written in Go (no dependencies at run time) that gets me from a fresh laptop to the right snippet in one command.

Source

Open source:github.com/raviteja3737/codeshelf. Snippets live in the snippets/ folder; each file name is its title.
